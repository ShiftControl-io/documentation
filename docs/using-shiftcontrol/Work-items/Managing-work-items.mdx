## Overview

The Work Items list is the operational view for admins. Use **My Work Items** to focus on items assigned to you, or **All Work Items** to review open work across the organization.

<ModeScreenshot path="WorkItems/Work-items-list" modes={["jc-google"]} alt="Admin Work Items queue grouped by app" />

## How It Works

Filter by status, type, source, assignee, watchers, approval state, or parent. Group the list by app or parent item to see individual steps alongside the larger request they support. The column chooser controls which details stay visible in the grid.

Row actions depend on the item's current status and your permissions. You can move eligible items between statuses, reassign work, or approve or deny a request when you are its approver. Select two or more rows to use bulk actions for status changes, approval decisions, reassignment, adding watchers, or changing due dates. Ineligible rows are skipped rather than given an action they cannot take.

### Create an Admin Work Item

Use **New work item** when a piece of work needs an owner and a place in the queue even though it did not start as an employee request.

The type selector includes app access requests; app grants, revocations, and reviews; group additions and removals; user provisioning, enabling, disabling, and deprovisioning; policy acknowledgements; app reconnects and renewal reviews; contact checks; and general tasks. App-removal and group-membership requests are submitted from the employee Directory, while system-generated items such as ownership handovers are not available in this form.

1. Choose a type and give the item a clear title. The type describes the work; the form only asks for target information when that type needs it.
2. Add a description and due date when they will help the assignee plan the work.
3. Choose an assignee and, if the task belongs to a larger effort, a parent item. Assigning an owner makes it clear who is expected to act.
4. Create the item. It appears in the queue and its assignee can follow it in My Work Items.

## Common Scenarios

### Triage overdue or unassigned work

Filter the list to the relevant status and assignee, then group by parent to see whether an item is one step in a larger request. Reassign the item if another admin is now responsible.

### Update several items after a review

Select the items that need the same change and use a bulk action. Review the confirmation summary, which shows how many selected items are eligible, before applying it.

## Step-by-Step Guide

1. Open **Work Items** in the admin navigation and choose **My Work Items** or **All Work Items**.
2. Set filters before taking action so the list contains the requests or tasks you intend to review.
3. Choose an app or parent grouping to see related steps together.
4. Use a row action for one item, or select several rows and choose a bulk action. Only actions allowed by the current status and your role are available.
5. Open an item to review its full details before changing ownership or making an approval decision.

## Things to Know

- Done and canceled items are excluded from the default open-work view; use the status filter to include them.
- Reassignment and approval decisions are permission-gated. A bulk action applies only to eligible selected items.
- Employees can update the status of their own assigned work, but they cannot reassign items or manage watchers from My Work Items.
